# 🌟 Fluent Flashcards (1,111 Sentences)

โปรเจกต์แอปพลิเคชัน Flashcard สำหรับฝึกฝนและท่องจำประโยคภาษาอังกฤษ-จีน 1,111 ประโยค พร้อมคำอ่าน (IPA/Pinyin) และคำแปลภาษาไทย โดยมีทั้งระบบ Web App แบบ Interactive และหน้าสำหรับสั่งพิมพ์เป็นเอกสาร PDF

## ✨ ฟีเจอร์หลัก (Key Features)
- **Multi-language Display**: แสดงผลแบบ 5 บรรทัด (ENG, IPA, CHI, PY, THAI) โดยอักษรจีนมีการเว้นวรรคให้อ่านง่าย
- **Keyword Highlighting**: เน้นคำสำคัญ (Keywords) อัตโนมัติด้วยตัวอักษรสีแดง-พื้นหลังสีเหลือง สำหรับคำที่ถูกครอบด้วยแท็ก `<span>`
- **Progress Tracking**: มีปุ่ม "Mark Mastered" เพื่อบันทึกประโยคที่จำได้แล้ว (หรี่แสงการ์ดลง) ข้อมูลถูกบันทึกไว้ใน `localStorage`
- **Smart Search & Filter**: ค้นหาประโยคที่ต้องการ และกรองตามหมวดหมู่ (เช่น ทักทาย, การทำงาน, ชีวิตประจำวัน)
- **Print-to-PDF Ready**: หน้าพิเศษ `print_pdf.html` สำหรับจัดเรียงการ์ดแบบ 3 คอลัมน์/หน้า พอดีกับการปริ้นลงกระดาษ A4
- **Automated Keyword Extraction**: สคริปต์ Python อัจฉริยะที่ช่วยดึงคำสำคัญจากแท็ก `<span>` ไปเก็บในตัวแปร Array `"key": []` ให้อัตโนมัติ โดยไม่ต้องมานั่งพิมพ์เองทีละคำ

## 📁 โครงสร้างไฟล์ (File Structure)
- `senten.html`: หน้าเว็บแอปพลิเคชันหลัก (UI สว่าง โค้งมน ทันสมัย)
- `print_pdf.html`: หน้าเว็บสำหรับจัดหน้าพิมพ์ PDF โดยเฉพาะ (บีบอัดขนาดเพื่อประหยัดหน้ากระดาษ)
- `code.py`: สคริปต์ Python สำหรับประมวลผลไฟล์ฐานข้อมูล 
- `data_with_highlights.txt`: ฐานข้อมูล JSON ที่เก็บข้อมูล 1,111 ประโยค หมวดหมู่ และแท็ก `<span>` ทั้งหมด

## 🚀 วิธีการใช้งาน (How to Run)

### 1. การเปิดใช้งานแอปพลิเคชันและหน้า Print PDF
เนื่องจากแอปมีการใช้คำสั่ง `fetch()` ดึงข้อมูลจากไฟล์ภายนอก จึงต้องรันผ่าน Local Web Server:
1. เปิดหน้าต่าง Command Prompt (CMD) หรือ Terminal ในโฟลเดอร์นี้
2. พิมพ์คำสั่ง: 
   ```bash
   python -m http.server 8000
   ```
3. เปิดเว็บเบราว์เซอร์ไปที่ลิงก์ต่อไปนี้:
   - **แอปท่องศัพท์หลัก**: http://localhost:8000/senten.html
   - **หน้าสั่งพิมพ์ PDF**: http://localhost:8000/print_pdf.html

### 2. การอัปเดตคำสำคัญ (Keywords)
หากคุณมีการเพิ่ม/แก้ไขคำศัพท์ด้วยการใส่ `<span>คำศัพท์</span>` ลงไปในไฟล์ `data_with_highlights.txt` ด้วยตนเอง และต้องการให้ระบบสกัดคำนั้นไปใส่ใน `"key": []` อย่างถูกต้อง:

1. เปิด Terminal ในโฟลเดอร์โปรเจกต์
2. พิมพ์คำสั่ง:
   ```bash
   python code.py
   ```
3. สคริปต์จะค้นหาแท็ก `<span>` ทั้งหมด (ในทุกภาษา) กรองคำที่ซ้ำกันออก แล้วบันทึกอัปเดตกลับลงไปในไฟล์ข้อมูลให้เรียบร้อย!
