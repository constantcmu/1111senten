# 🌟 Fluent Flashcards (1,111 Sentences)

โปรเจกต์แอปพลิเคชัน Flashcard สำหรับฝึกฝนและท่องจำประโยคภาษาอังกฤษ-จีน 1,111 ประโยค พร้อมคำอ่าน (IPA/Pinyin) และคำแปลภาษาไทย โดยมีทั้งระบบ Web App แบบ Interactive ที่มีเสียงอ่าน และหน้าสำหรับสั่งพิมพ์เป็นเอกสาร PDF

## ✨ ฟีเจอร์หลัก (Key Features)
- **Multi-language Display**: แสดงผลครบ 5 รูปแบบ (ENG, IPA, CHI, PY, THAI) โดยตัวหน้าเว็บจัดการระเบียบการเว้นวรรคของอักษรจีนให้อ่านง่ายขึ้น แต่ยังคงรักษาโครงสร้างของแท็ก HTML ได้อย่างสมบูรณ์
- **Smart Keyword Highlighting**: เน้นคำสำคัญ (Keywords) อัตโนมัติด้วยตัวอักษรสีแดง-พื้นหลังสีครีม (อ้างอิงดีไซน์เดียวกันทั้งหมด) สำหรับคำที่ถูกครอบด้วยแท็ก `<span>` ทั้งในประโยคภาษาอังกฤษและภาษาจีน
- **Text-to-Speech (TTS)**: ระบบอ่านออกเสียงประโยคภาษาอังกฤษและภาษาจีน สามารถฟังเสียงได้ทันที เพียงใช้เมาส์คลิกที่ข้อความ หรือ IPA/Pinyin บนหน้า Flashcard (ใช้ Web Speech API จากเบราว์เซอร์โดยตรง)
- **Progress Tracking**: มีปุ่ม "Mark Mastered" เพื่อบันทึกประโยคที่จดจำได้แล้ว (การ์ดจะเปลี่ยนสถานะเป็นสีเขียวขึ้นเครื่องหมายถูก) โดยข้อมูลความคืบหน้าจะถูกบันทึกไว้ใน `localStorage`
- **Smart Search & Filter**: ค้นหาประโยคที่ต้องการง่ายดาย และกรองตามหมวดหมู่ได้สะดวกรวดเร็ว
- **Print-to-PDF Ready**: หน้าแยกเฉพาะ `print_pdf.html` ถูกออกแบบมาสำหรับจัดเรียงการ์ดแบบ 2 คอลัมน์ต่อหน้า บีบอัดพื้นที่ให้กระชับและพอดีกับการปริ้นลงกระดาษ A4 อัตโนมัติ

## 📁 โครงสร้างไฟล์ (File Structure)
- `senten.html`: หน้าเว็บแอปพลิเคชันหลัก (UI ดูสว่าง ทันสมัย เป็นมิตรต่อการเรียนรู้ มาพร้อมปุ่มสั่งพลิกการ์ดและเล่นเสียง)
- `print_pdf.html`: หน้าจอแสดงผลออกแบบเพื่อสั่งรัน `window.print()` ทำเป็นไฟล์ PDF ไว้จดจำและไฮไลต์บนกระดาษ
- `data_with_highlights.bak.json` / `fill.json`: ฐานข้อมูลหลัก (JSON) ที่อัปเดตบรรจุข้อมูลทั้ง 1,111 ประโยค หมวดหมู่ และแท็ก `<span>` ภาษาจีน-อังกฤษ
- `code.py` / `patch_ch_spans.py`: ชุดสคริปต์ Python เครื่องมือช่วยจัดการดึงและแก้ไขแท็กฐานข้อมูล JSON เบื้องหลัง

## 🚀 วิธีการใช้งาน (How to Run)

### 1. การเปิดใช้งานแอปพลิเคชันและหน้า Print PDF
เนื่องจากแอปพึ่งพาการใช้คำสั่ง `fetch()` ดึงข้อมูลจากไฟล์ภายนอก (`data_with_highlights.bak.json`) จึงจำเป็นต้องรันผ่าน Local Web Server ไปยังเบราว์เซอร์:
1. เปิดหน้าต่าง Command Prompt (CMD) หรือคลิกขวาเปิด Terminal ภายในโฟลเดอร์ของโปรเจกต์นี้
2. รันคำสั่งเซิร์ฟเวอร์ด้วยไพธอน: 
   ```bash
   python -m http.server 8000
   ```
3. จากนั้นเปิด Web Browser (เช่น Chrome/Edge) เสิร์ซ URL ไปที่:
   - **แอปท่องศัพท์หลัก**: http://localhost:8000/senten.html
   - **หน้าสั่งปริ้น PDF**: http://localhost:8000/print_pdf.html
*(หรือใช้งาน Extension ที่ชื่อว่า `Live Server` ผ่านโปรแกรม VS Code ก็ได้เช่นกัน)*

### 2. การฟังเสียงอ่าน (Text-to-Speech)
- ในหน้าแอป `senten.html` หากต้องการฟังเสียง **สำเนียงภาษาอังกฤษ** ให้เอาเม้าส์ไปคลิกบริเวณประโยคภาษาอังกฤษ หรือข้อความฝั่ง (IPA)
- หากต้องการฟังเสียง **สำเนียงภาษาจีน** ให้เอาเมาส์คลิกส่วนอักษรจีน (中文) หรือข้อความพินอิน (PINYIN)
*(หมายเหตุ: ระบบเบื้องหลังจะทำการล้างแท็ก <span> ออกให้โดยอัตโนมัติก่อนส่งตัวอักษรเข้าเครื่องอ่าน ทำให้เสียงอ่านของระบบออกมาได้อย่างต่อเนื่องและเป็นธรรมชาติ)*

### 3. การออนไลน์เว็ปไซต์ฟรีด้วย GitHub Pages (Deployment)
เนื่องจากแอปพลิเคชันนี้ทำงานประมวลผลบนเบราว์เซอร์ทั้งหมด จึงสามารถนำขึ้นไปรันออนไลน์บน **GitHub Pages** ได้ฟรี 100% ตลอดชีพ:

1. นำโค้ดทั้งหมด (Commit & Push) ขึ้น GitHub Repository ของคุณตามปกติ
2. เปิดเบราว์เซอร์เข้าไปที่หน้า Repository นั้นบน GitHub
3. ไปที่เมนู **Settings** ⚙️ (อยู่แถบเมนูด้านบนขวา)
4. มองหาเมนูด้านซ้ายและลากลงมาคลิกที่ **Pages** (ในหมวด *Code and automation*)
5. ในหัวข้อ **Build and deployment** > แถบ **Source** ตรวจสอบว่าเลือก `Deploy from a branch`
6. ในแถบ **Branch** ให้คลิกแก้ไขจาก `None` เลือกเป็น Branch หลักสุดของคุณ (เช่น `main` หรือ `master`) และช่องโฟลเดอร์ให้เป็น `/ (root)` แล้วกด **Save**
7. รอให้ระบบ GitHub ประมวลผลประมาณ 1-2 นาที เมื่อหน้าเว็บพร้อม จะมีป๊อปอัปแจ้งเตือนให้คุณทราบถึง URL เว็บไซต์จริงของคุณ (เช่น `https://[username].github.io/[repo-name]/`)

**วิธีการเข้าถึงแอป (ลิงก์ URL):**
ต่อท้าย URL ที่ได้ด้วยชื่อไฟล์ที่ต้องการรัน:
- หน้าแอปหลัก: `https://[username].github.io/[repo-name]/senten.html`
- หน้าพิมพ์ PDF: `https://[username].github.io/[repo-name]/print_pdf.html`
*(เทคนิค: หากอยากให้การเข้าลิงก์หลักของคุณเปิดหน้าแอพทันที ควรเปลี่ยนชื่อไฟล์ `senten.html` ให้เป็น `index.html` แล้ว Push โค้ดขึ้นไปใหม่ครับ)*
